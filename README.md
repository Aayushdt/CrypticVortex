## Expense Tracking Made Simple

Evenly is a sleek, user-friendly web application designed to help you track and split expenses among friends, roommates, or colleagues with ease. Whether you're managing cafeteria bills, planning trips, or sharing costs for any group activity, Evenly makes the process transparent and hassle-free.

## Features

 #### 1. Journey-Based Expense Management:
 - Organize expenses into different "journeys" or categories (trips, events, household, etc.)

#### 2. Real-Time Settlements:
- Calculate who owes whom with a single click
#### 3. Smart Expense Distribution: 
Automatically distribute expenses evenly among participants
#### 4. Visual Settlement Indicators: 
- Easily see which journeys have been fully settled
#### 5. Person Management: 
- Add and manage people within each journey
#### 6. Responsive Design: 
- Works seamlessly on desktop and mobile devices
####  7. Interactive Sidebar: 
- Collapsible navigation for a distraction-free experience  

## Working

1. **Home Page**: 
   - The home page provides an overview of **Eveny**, explaining its purpose as an expense tracker designed for daily use. It highlights key features and benefits, encouraging users to manage their finances effectively.
   - From the home page, users can easily navigate to the **Login Page**.

2. **Login Page**: 
   - Users can create a new account or log in with existing credentials. This secure authentication process ensures that each user's financial data remains private and protected.

3. **Expense Tracker Home Page**: 
   - After logging in, users are directed to the expense tracker home page, which includes:
     - **Add New Trip**: Users can create a new trip, allowing them to categorize expenses by trip.
     - **Add New Items**: A form to input details of new expenses related to the trip, including the amount, category, and date.
     - **Total Expenses**: The application displays the total expenses for the trip, providing users with a clear overview of their spending.
     - **Total People in the Trip**: Users can specify the number of people involved in the trip, allowing for shared expense tracking.
     - **Individual Expense Tracking**: The app shows each person's expenses, making it easy to see who spent what during the trip.
     - **Personal Profile Icon**: Each user has a personal profile icon that can be clicked to access their account settings and preferences.
     - **Monthly Expense Overview**: A section that summarizes the user's total expenses for the month, helping them stay on top of their financial goals.

4. **User  Experience**: 
   - The application is designed for ease of use, with smooth transitions and animations powered by GSAP, enhancing the overall user experience.
