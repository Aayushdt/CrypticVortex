Evenly is a smart bill-splitting website designed to make splitting expenses among friends , roommate, or colleagues effortless and fair . Whether you're dining out , sharing rent, or planning a group trip , Evenly ensures everyone pays their fair share without the hassle of manual calculations.


## Tech Stack

**Frontend**  Html , Css ,Javascript 

**Styling** tailwind CSS + Custom Properties

**Fonts:**  Google Fonts (Poppins)

**Animations:** Animate.css




## Features

- Light/dark mode toggle
- Expense Tracking
- Smart Settlements
- Animations
- Responsive UI

## FAQ

#### Que. How do I add a new expense ?
Click the "Start a Journey " button, fill in the details (amount, payer, category), and save. The app will auto-calculate who owes whom.

#### Where is my data stored ? 

Currently, data is stored only in your browser memory (no backend). Refreshing the page will clear it unless you enable localStorage (future update). 

####  How do settlements work ? 

The app calculates net balances and suggests the minimum transactions needed to settle debts (e.g., "Himanshu pays Aayush Rs.10").
